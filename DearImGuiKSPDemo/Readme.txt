DearImGuiKSPDemo - demo and benchmark mod for DearImGui-KSP

This is an optional showcase mod for the DearImGuiKSP UI library: widget and
theming demos, plotting and animation examples, a telemetry panel, and a
benchmark UI. It is NOT required to use the library - consumer mods depend on
DearImGuiKSP directly.

Install: extract the zip into your KSP root so the files land in
GameData\DearImGuiKSPDemo\.

Requires: DearImGuiKSP 1.x, installed separately (GameData\DearImGuiKSP\).
